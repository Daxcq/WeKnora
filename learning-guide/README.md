> 本手册所有章节都基于 D:\WeKnora 仓库的真实代码撰写，引用的文件路径和行号均可直接点开对照阅读。
> 适用版本：main 分支（含插件框架，commit `5c32818a` 之后）。

```

  01 初识 WeKnora 与 RAG
  02 前置课 A：RAG 核心概念
  03 前置课 B：工程模式速成

  11 Agent：ReAct 循环
  12 Graph RAG：知识图谱
```

建议顺序：**1→2→3→4→5→6→7→11→12**，其余按需。第 7 章之后插件化四篇连读效果最佳；13/14 与"增量缓存"工作直接相关，做相关工作前必读。

## 进度自测清单

每章末尾有自测题，全部答案集中在附录 A。全部答上来即毕业：

- [ ] 能说清 RAG 写路径 5 个站点和读路径 9 个插件各自干什么
- [ ] 能解释为什么异步边界画在"入库"与"处理"之间
- [ ] 能从空目录写出一个能被 WeKnora 加载的插件
- [ ] 能讲清 `--network none` 的容器为什么还能跑 gRPC
- [ ] 能说清"代码定围栏、LLM 做选择"的分工及其原因
- [ ] 能解释图谱为什么整图重建而向量可以增量
